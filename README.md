# Ayush Raj — Portfolio

Personal technology and engineering portfolio showcasing artificial intelligence systems, large language models, retrieval-augmented generation (RAG), computer vision pipelines, and full-stack software development.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Core**: React 18, JavaScript / ES Modules
- **Styling**: Vanilla CSS Modules (Design tokens & responsive architecture)
- **Typography**: Plus Jakarta Sans, Inter, JetBrains Mono
- **Content**: Markdown / Gray-matter / Remark

## Features

- **IntroCover**: High-performance procedural volumetric smoke engine with interactive mouse-motion dynamics and luxury editorial typography.
- **AI / LLM Systems Lab**: Neural core and orbital intelligence architecture highlighting real-time computer vision, RAG, and autonomous agent workflows.
- **Theme System**: Seamless dark and light modes with localStorage persistence and zero-flicker pre-hydration.
- **Verified Metrics & Projects**: Industrial safety vision pipeline (BCCL dataset), Artificial Wisdom semantic retrieval, and full-stack production systems.
- **Interactive Direct Contact**: Quick email and direct telephone connectivity (`+91 9905316254`) with one-click clipboard copying and accessibility compliance.
- **Performance & SEO**: Fully optimized static export build with responsive layouts and semantic hierarchy.

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application in the browser.

## Production Build

```bash
npm run build
npm start
```
